# Labs_scan_ports
Attaquant : kali
Cible : Ubuntu
Hyperviseur : VirtualBox
Machine local : Linux Mint

En utilisant les deux machines virtuelles, et après les avoirs interconnectes, j'utilise kali pour tester les ports de mon Ubuntu pour repérer les ports ouverts grace a nmap. 

Ensuite je capture ce qui se passe avec wireshark

Au départ,comme Ubuntu venait d’être installe, tout les ports étaient fermes donc il fallait instaure 2 ports ( ssh et apache2 )
